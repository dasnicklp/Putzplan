Sprachassistent

„Hey Siri, Einkaufsliste“ → „Milch und Eier“ → steht auf der Liste, beim anderen mit Mitteilung (wenn eingeschaltet).

So geht's auf dem iPhone
  1. Oben „Link kopieren“ tippen.
  2. App „Kurzbefehle“ öffnen, oben rechts „+“.
  3. Aktion „Text diktieren“ hinzufügen.
  4. Aktion „Inhalte von URL abrufen“ hinzufügen und als URL den kopierten Link einfügen.
  5. In dieser Aktion auf den Pfeil tippen: Methode „POST“, Anfragetext „Formular“. Mit „Neues Feld hinzufügen → Text“ ein Feld anlegen: Schlüssel t, Wert „Diktierter Text“.
  6. Aktion „Text sprechen“ hinzufügen. Siri sagt dann z. B. „Milch steht jetzt auf der Einkaufsliste.“
  7. Den Kurzbefehl oben „Einkaufsliste“ nennen. Fertig: „Hey Siri, Einkaufsliste“.
Und auf Android?

Der Google Assistant kann leider keine eigenen Links aufrufen. Am schnellsten: lange auf das App-Symbol drücken → „Einkaufsliste“ und das Mikrofon der Tastatur benutzen. Wer es per Sprache will: Mit der kostenlosen App „HTTP Shortcuts“ einen Shortcut anlegen (Methode POST, Adresse = Link, Formular-Feld t = eingegebener Text) und auf den Startbildschirm legen.
